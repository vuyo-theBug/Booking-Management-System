# Samnath Optometrists Booking Management System

## Project Overview

The Samnath Optometrists Booking Management System is a booking solution developed to help an optometry practice manage patient appointments more efficiently. The project was designed to replace the traditional manual booking process with a digital system that makes appointment scheduling, patient management and record keeping easier.

The solution consists of a web-based booking application and a Windows desktop application, both connected to a Microsoft SQL Server database to maintain and manage booking information.

This was a collaborative university project that provided practical experience in software development, database management, system integration and problem-solving.

## Key Features

- User Registration and Login: Allows users to create accounts and securely access the booking system.
- Appointment Booking: Enables users to schedule appointments through the web application.
- Double-Booking Prevention: Helps prevent multiple patients from booking the same appointment slot.
- Appointment Management:Supports the management and organisation of booking information.
- Database Integration: Uses Microsoft SQL Server to store and manage application data.
- Desktop Application:Includes a Windows Forms application connected to the same database.
- Data Management and Reporting: Supports the organisation and retrieval of booking information.

## System Components

### 1. Web-Based Booking Application

The web application provides an interface through which users can register, log in and book appointments. It was developed using ASP.NET, C#, HTML, CSS and JavaScript.

### 2. Windows Desktop Application

The desktop application was developed using C# Windows Forms. It provides an additional interface for managing and accessing booking information stored in the shared database.

### 3. Database

Microsoft SQL Server was used to design and manage the relational database. Both applications connect to the database to access and maintain booking information.
